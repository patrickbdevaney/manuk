# W6.R1 — render decision instrument: actionable-geometry fidelity (AGF) and near-bar miss survey

chrome_ver=145.0.7632.116 (MANUK_CHROME_PIN). Viewport 1024x768 for both engines. Manuk: `target/release/agf-probe`
(new bin, `agent/src/bin/agf-probe.rs`). Chrome oracle, matching, survey: `bench/agent-tasks/r1_agf.py`.
Raw captures: `docs/sprint/w6/raw/R1/` (one JSON per site and run, 33 captures). Tables: `agf-runs.tsv`,
`miss-survey.tsv`, `summary.json`.

## Method (fixed before reading numbers)

- **Targets.** Chrome accessibility tree (`Accessibility.getFullAXTree`), roles button, link, checkbox, radio,
  textbox, searchbox, combobox, switch, menuitem(+checkbox/radio), tab, option; non-empty name; non-empty border box
  (`DOM.getBoxModel`); centre inside the 1024x768 viewport. Below-fold and box-less targets are counted, not scored.
- **Match.** Key (role, name); k-th Chrome target pairs with k-th manuk target of the same key.
- **AGF-OK.** Matched AND IoU(Chrome border box, manuk bbox) >= 0.9 AND manuk's top hit-test element at its bbox
  centre is the target or a descendant (the `drivability` criterion).
- **AGF(site)** = AGF-OK / scored targets. Misses classed `missing` | `geom` | `hit`.
- **Survey keys (Chrome side).** font = first computed font-family; owner = display of the nearest ancestor that
  establishes flex/grid/table formatting context (`block-flow` when none).
- **Spearman** between site AGF and the site's REAL manuk pass rate (`bench-queue/out/rg2b-real-manuk.tsv`, pinned
  chrome_ver, mean over tasks and runs).
- **Falsifier (node row):** AGF >= 95% OR no correlation OR no key > 25% of misses -> freeze render work at Taffy-bump hygiene.

Pooled over 33 captures: **341 misses**, of which 341 are geometry or missing, **0 are hit-test failures**.

**Interpretation of the 0.000.** Every scored site fails on `geom`, not on `hit`, so the hit-test half of AGF is
never the binding constraint. The geometry failure is dominated by **page-position offsets**, not sizes. Chrome's
scroll is 0 on these pages (checked: udriver, staynb, dashdish), so this is not a scroll artefact. On udriver,
Chrome places the header at y=204 while manuk places it at y=0, so Chrome renders about 204 px of content above
the header that manuk does not. On staynb the offset is about 250 px and on dashdish about 33 px. This is a real
page-content or layout difference between the engines on these live replicas. What exactly manuk omits above the
header is **not yet identified** (follow-up W6.R1.a).

Size-only diagnostic, position ignored (`|dw|,|dh| <= 2 px`): **128 / 281 = 45.6%** of matched targets. Sizes
agree about half the time; positions do not agree.

## Falsifier evaluation

| clause | status |
|---|---|
| AGF >= 95% | **not met** (0.000 on all 9 scored sites) |
| no correlation (AGF vs REAL pass) | **not evaluable** (AGF has zero variance; rho undefined) |
| no key > 25% of misses | **not met** (owner `flex` = 97.4%) |

Freezing render work requires the falsifier to fire. Here it did not fire on a measured clause: AGF is far from
95%, and a dominant key exists. The correlation clause is undefined, so the instrument does not decide the question
by itself. **Decision: render work is not frozen by this node.** The next render decision needs the offset cause
(W6.R1.a) and a site-level AGF that varies, before a correlation can be read.

## Instability and capture caveats (recorded, not scored)

- **gomail:** Chrome AX tree had 0 scorable targets in 3/3 runs while manuk has 125. Excluded. Not investigated
  further here; likely a Chrome render or state issue on this replica.
- **fly-unified:** Chrome had 49 targets in run 1, but 4 in runs 2 and 3, while manuk had 48 in all three runs.
  Run 1 is the outlier in target count; the other two runs' AGF is over a much smaller set.
- **opendining:** manuk had 10, 0, 10 targets across the three runs (client-side failure, matching the known REAL
  opendining issue). Chrome had 109 in all three. The manuk side is intermittent.
- **Capture integrity:** the first attempt at the capture ran twice concurrently and was killed. The final captures
  came from a single process (`r1-capture3.log`, relaunched cleanly). The three full runs are complete.
- **REAL pass data:** `rg2b-real-manuk.tsv` has 10 sites (omnizon absent). Per-site pass means: dashdish 0.636,
  fly-unified 0.238, gocalendar 0.433, networkin 0.600, opendining 0.800, staynb 0.222, topwork 0.037,
  udriver 0.758, zilloft 0.133.

## Not measured (stated, not hidden)

- Whether the offset is a font-loading difference, a missing top banner, or a height difference. This needs the
  element-level diff in W6.R1.a.
- Offset-free position matching. Only the size diagnostic is offset-free; a correlation on it is a candidate
  follow-up.
- Per-task (not per-site) correlation. The node asked for per-task pass; this run uses site-level pass means.

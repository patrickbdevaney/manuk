## The R2.1 task list (11 tasks: F01-F08, F10, L11, L12)

except **F08** (1/3).

  head): 3/3 each.
- **F08 (infinite-scroll feed, "What is the text of item 45?") is 1/3.** The two failing runs answered
  "Item 45 is **amber**", which is the correct value, but the verifier requires the literal string `Item 45: amber`.

  the suite was not changed (SUCCESS.md: no tuning after results). It is recorded as `judge-error`
  (`verifier-literal-mismatch`) in `docs/sprint/FAILURES.tsv`. The fix is a new suite version (a new comparison,
  per SUCCESS.md), which is an owner decision; a follow-up node is queued for it.

### CB.SANDBOX audit (2026-10-30): which Chrome did the cdp-layer / playwright rows actually run?

Before this node, `CdpBackend::launch` always passed `--no-sandbox` and the harness resolved Chrome with `shutil.which("google-chrome")`.
On the interactive PATH that is the pinned CfT 145.0.7632.116, but `/usr/bin/google-chrome` on the same box is Chrome 156.0.8078.47,
so a harness started with a different PATH would have run 156. The transcripts in `docs/sprint/arm3/` carry no Chrome version string, and

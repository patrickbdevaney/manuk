# W5.G1: why cdp-layer trails Playwright on the same Chrome (10-task slice)

chrome_ver=145.0.7632.116 (`$MANUK_CHROME_PIN`, every row in `G1/*.tsv`), Haiku, REAL agisdk 0.3.5 v1 clones,
`claude -p` through the REAL shim. Scoring is REAL's own jmespath rule; the 64 llm_boolean evals are unscored, and
none of these 10 tasks holds one, so no judge key was used.

## Design
- **Tasks:** the 10 REAL tasks with Playwright >=2 passes out of its existing runs and cdp-layer <2 passes out of its
  existing runs (`docs/sprint/w4/A6-real.tsv`, `docs/sprint/w318/real-runs.tsv`; the selection is from those rows, not
  from the new runs). Playwright passes on these same tasks in those prior runs: 4/4 on 8 tasks, and 2/4 on gomail-3 and
  gomail-8. Playwright was not re-run here.
- **(a) cdp-layer:** the current observation, 3 runs x 10 tasks = 30 runs.
- **(b) cdp-layer+pwfmt:** same binary and Chrome, same tool surface, same handles. The REAL shim re-lays each
  observation line in Playwright MCP's snapshot shape (`- button "User" [ref=h2]`, `[level=N]` on headings), see
  `pw_snapshot` in `bench/agent-tasks/real_run.py`. It is a layout adapter only: the `in <container>` suffixes are
  dropped and manuk's handles are kept, so act and type resolve unchanged. Nesting by indentation is NOT reproduced.
  30 runs.

## Failure classes (agent-side; `G1/causes.tsv`, one class per failed run, 41 failed runs)
Precedence: turn-limit > tool-choice > act > target > perceive. Runs read by `real_classify.parse`/`features`, reused
unchanged from W4.A0.
- `turn-limit`: the claude run errored or hit the 420 s cap. **0** in both arms.
- `tool-choice`: the agent issued no action call at all. **2** in (a), **2** in (b).
- `act`: a browser-side refusal or no-effect that the agent saw in a result (`no change | url: unchanged` on two or
  more results, STALE or unknown handles, a typed value that did not register, unsupported action, or a timeout).
  **13** in (a), **7** in (b). Top class for (a).
- `target`: an occluding overlay or dialog, a strict-mode or ambiguous target. **6** in (a), **11** in (b). Top class for (b).
- `perceive`: an answer with no action-side or target-side signal. **0** in both arms. Every failed run had one of
  those signals, so this class was never assigned. It may undercount agent misreads (a wrong answer after a clean run).

**Top 2 failure classes:** (a) `act` (13) then `target` (6); (b) `target` (11) then `act` (7). The shift from act to
target under (b) is the one visible effect of the format: the Playwright-shaped lines expose the overlay and dialog
nodes that manuk's own lines hide. It did not turn those into passes.

## Checks
- `python3 -I bench/agent-tasks/w5g1_report.py` exits 0 (GATE PASS): 30 rows per arm, 3 runs per (arm, task), a
  transcript for every run, every failed run classed.
- Mutant `--mutate drop-act` (the `act` rule removed, so its runs go unclassified) exits 1 with 20 unclassified runs
  per arm. Red as required.
- Hand check, 3 act-labelled runs read in full: dashdish-7 r1 (click `no change`, typed text not registered, stale
  handle), gomail-3 r1 (repeated STALE handles behind a modal), gomail-8 r1 (`no change` on Escape). The labels
  match. The act and target rules are regex over agent text and results, so they are a sample check, not a validated
  classifier.

## What this says about the 52-vs-35 gap
This slice is 10 tasks, not the full 102-task REAL set, and the Playwright baseline rows are from earlier runs on a
mix of dates (same chrome_ver). The slice cannot reproduce the 52-vs-35 aggregate, so it cannot say what fraction of
that gap the format explains. What it does say: on these tasks the snapshot shape is not the cause; the failures are
action-side (no-change clicks, stale handles after a re-render) and target-side (overlays, ambiguous controls).
Those are the next places to look. Follow-ups are W5.G1.a (stale handles) and W5.G1.b (hand-label the class rules).

## Caveats
- 3 runs per cell: a 1-task change is noise.
- The adapter does not reproduce Playwright's nesting or its `[ref=e…]` naming; a model trained on that format may still
  behave differently. This is layout only.
- The Playwright column is historical data, not re-measured here.
